# Hyper Connectivity and Instability in Socio Ecological Networks
This repository contains both R and Julia scripts to make empirical figures and run simulation experiments of the manuscript "Hyper Connectivity and Instability in Socio Ecological Networks".

Data for the empirical figures were pulled from a variety of sources listed in Supplementary Materials of Manuscript.
